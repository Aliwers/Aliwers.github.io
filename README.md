# Мега Драйв II

**Публичная версия: https://aliwers.github.io/**
Репозиторий: https://github.com/Aliwers/Aliwers.github.io

Каталог из 144 игр Sega Mega Drive II и рабочий эмулятор в браузере,
оформленные как телевизор конца 90-х.

## Запуск

Двойной клик по `start.command`. Откроется браузер на `http://127.0.0.1:8777`.

Или вручную:

```bash
python3 -m http.server 8777
```

Просто открыть `index.html` двойным кликом **нельзя**: браузер блокирует
загрузку ROM по протоколу `file://`. Нужен любой локальный HTTP-сервер.

Для эмулятора нужен интернет — ядро эмуляции (~10 МБ) грузится с CDN
при первом запуске игры. Сам каталог работает офлайн.

## Что здесь есть

- **137 классических игр** — только описания: год, жанр, студия, издатель,
  число игроков. ROM этих игр защищены авторским правом и в комплект не входят.
- **7 играбельных картриджей** — свободно распространяемые homebrew-игры и демо,
  которые авторы сами выложили в открытый доступ. Запускаются сразу.
- **Свой картридж** — перетащите файл `.md`, `.bin`, `.gen`, `.smd` или `.zip`
  на страницу. Файл никуда не отправляется, эмулятор читает его из памяти браузера.

## Структура

```
index.html          страница
player.html         изолированный запуск эмулятора в iframe
start.command       локальный сервер + открыть браузер
assets/css/main.css страница, каталог, типографика
assets/css/crt.css  телевизор и эффекты кинескопа
assets/js/data.js   жанры и 7 играбельных картриджей
assets/js/catalog.js справочник 137 классических игр
assets/js/art.js    процедурные обложки
assets/js/app.js    фильтры, каналы, запуск игр
assets/img/room-*.svg комната вокруг телевизора
check-rom.mjs       проверка поиска картриджей (node check-rom.mjs)
roms/               homebrew-картриджи (см. CREDITS.md)
```

## Обложки

Скриншотов игр на странице нет. Для каждой игры обложка рисуется кодом:
хеш названия задаёт зерно генератора, жанр — базовый тон и тип сцены,
случайный бросок — время суток и композицию. Одно название всегда даёт
одну и ту же картинку.

## Комната

Телевизор стоит не в пустоте, а в квартире начала девяностых: обои в мелкий
цветочек и паркет нарисованы в CSS, остальное — три SVG в `assets/img/`.
`room-wall.svg` — ковёр на четырёх гвоздях, фотография в рамке и настенные
часы. `room-left.svg` — Mega Drive II на полу, джойстик, витые провода и
картриджи стопкой. `room-right.svg` — персидский кот, волнистый попугай в
клетке, алоэ, герань и традесканция. Слой декоративный: клики проходят
насквозь, на экранах уже 1180px боковины убираются, ковёр и пол остаются.

## Эмуляция

[EmulatorJS](https://emulatorjs.org/), ядро `genesis_plus_gx`.
Управление, сохранения и настройки — в меню самого эмулятора.

## Отличия локальной версии от публичной

Локально папка `roms/` на месте, поэтому все семь картриджей запускаются сразу.
На GitHub Pages их нет (14 МБ бинарников в репозитории), поэтому там:
Masiaka и Sega 2048 играются с CDN, остальные предлагают скачать файл у автора
и перетащить на страницу. Чтобы всё играло и онлайн — загрузите папку `roms/`
в репозиторий через веб-интерфейс GitHub.

## Известные ограничения

- Ядро эмуляции грузится с CDN, офлайн игры не запустятся.
- Интерфейс эмулятора на русском есть только в сборке `latest`, поэтому
  используется она, а не `stable`.
- Классические игры нельзя запустить без своего ROM — это осознанное решение,
  а не недоделка.
